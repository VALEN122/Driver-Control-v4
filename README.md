# Driver Control v4.2

Proyecto Android preparado para compilar con GitHub Actions.

## Compilar
1. Subir todo este proyecto a un repositorio GitHub.
2. Abrir la pestaña **Actions**.
3. Elegir **Build Android APK**.
4. Ejecutar **Run workflow** (o esperar al build automático tras subir a `main`).
5. Al finalizar, descargar el artifact **DriverControl-v4.2-APK**.
