# Driver Control 6.1.0 — inicio financiero 10X

## Cambios visibles

- Inicio completamente reorganizado alrededor de una sola respuesta: cuánto dinero real quedó.
- Estado de jornada y acción principal visibles sin desplazarse.
- Acciones rápidas para viaje, gasto, vuelto e historial.
- Tarjeta personalizada con una recomendación financiera breve.
- Resumen de ingresos, nafta, gastos, viajes y kilómetros con textos cortos.
- Identificación visible de la versión instalada.
- Diseño con más espacio y alturas seguras para evitar textos superpuestos.

## Protección de datos

- Nueva copia de seguridad SQLite compartible desde Ajustes.
- Mensaje explícito que advierte hacer una copia antes de desinstalar.
- El Excel continúa disponible como informe; la copia SQLite conserva la base completa.

## Verificación

- Pruebas de cálculo, conciliación, Excel e integración Android.
- Compilación Python sin errores de sintaxis.
- El APK debe compilarse con una firma de prueba persistente para que las próximas
  versiones puedan instalarse encima sin borrar los datos.
