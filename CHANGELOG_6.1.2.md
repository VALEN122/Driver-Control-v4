# Driver Control 6.1.2 — inicio y exportaciones corregidos

- El inicio usa el mismo azul de marca como fondo nativo y elimina las franjas negras en pantallas alargadas.
- Excel y copias de seguridad se comparten mediante un puente Android nativo.
- Las exportaciones usan un `content://` URI temporal y compatible con Drive, Archivos, correo y mensajería.
- Se conserva el mismo identificador de paquete y la misma firma para actualizar sin borrar los datos.
